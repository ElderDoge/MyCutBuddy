# 剪搭子（MyCutBuddy）· AI 剪辑 Skill

不生产 AI 生成画面：完全按传统人工剪辑的思路和方法分析你的素材库和文案，剪出效果接近人工精剪的短视频，并导入你电脑上的剪映专业版。

剪搭子是一套装进 Agent 就能用的 AI 剪辑系统。它先读懂文案，再从素材库挑画面、排节奏，最后加花字、音效、字幕、贴纸、调色和重点标注，产出可继续编辑的剪映专业版草稿。你只需要打开剪映检查、微调、导出。剪辑风格和逻辑可任意调整，以便符合交付标准和要求。

装上它之后，传素材、做预设、提交任务、等结果、下载草稿并装进剪映，全部交给 Agent；你直接提要求即可。

## 适合剪什么内容

电商信息流广告、品牌推广、产品推广、个人自媒体、跨境电商广告、实体店铺推广、本地生活等题材，时长 10 秒～3 分钟的短视频。不限赛道、不限内容方向。

## 适合剪什么形式

- 旁白配音型视频（AI配音、自己配音或导入其他软件配音皆可）
- 出镜口播型视频（真人出镜、主播出镜、老板出镜、AI数字人出镜讲解等形式）

## 不适合剪什么形式

- 无讲解或少语音的形式（剪辑依赖语音驱动）

## 适合谁

- 专业剪辑师、专业剪辑团队
- 品牌方内容团队
- 个人创作者

## 为什么用 Agent 操作剪搭子

- **不用自己操作**：素材导入、预设调整、任务提交、进度跟踪、草稿安装都由 Agent 完成，你只做最后的检查。
- **直接提要求**：不用研究参数怎么填、按钮怎么点，把「节奏快一点」「提到这个卖点就配对应画面」说清楚，Agent 自己判断该怎么调。
- **不用先读文档教程**：遇到问题直接问 Agent，它去查规则和接口再动手。

## 能力

- 项目与素材库管理：主素材库、人物口播库、语音配音库。
- 素材导入与索引：百度网盘上传、分享、转存；上千条素材不用提前分类。
- 风格与字幕样式预设：个人预设创建与管理；剪映里做好的字幕和固定文字样式提取。
- 剪辑：旁白剪辑与人物出镜口播都支持，单条或批量提交；批量逐行确认差异。
- 交付：下载草稿包、解压、安装到本机剪映草稿目录。

## 安装

把下面这句话发给你的 Agent：

> 请帮我安装 mycutbuddy/MyCutBuddy 这个 skill（Gitee 或 GitHub）

也可以让 Agent 按自己的技能安装方式处理，或在终端执行：

```bash
npx skills add https://gitee.com/mycutbuddy/mycutbuddy.git
```

适合 Windows 和 MacOS。

要求 Node ≥20，并已安装剪映专业版。推荐同时安装官方百度网盘 Skill（`baidu-drive`），用于素材上传与下载。

也可以把本仓库克隆到 Agent 的 skills 目录。安装后 CLI 位于 Skill 根目录的 `scripts/mycutbuddy.mjs`，全部能力通过 `node scripts/mycutbuddy.mjs <命令>` 调用，命令清单以 `help` 输出为准。

## 首次使用

1. 让 Agent 发起账号授权，按提示在浏览器中批准授权。凭据只保存在本机 `~/.mycutbuddy`，有效期 30 天。
2. 新手机号完成短信验证注册即赠 200 积分；用完后随用随充。
3. 直接与 Agent 对话以开始剪辑。

## 边界

- 本地草稿安装需要 Agent 具备这台电脑的文件访问权限；纯云端环境只能提供下载信息与手动安装步骤。
- 同一套剪辑能力另有网页工作台入口，但本 Skill 面向 Agent 操作。
