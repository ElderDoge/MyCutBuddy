# 剪搭子（MyCutBuddy）· AI 剪辑 Skill

不生产 AI 生成画面：完全按人工剪辑的思路分析你的素材库和文案，剪出效果接近人工精剪的短视频，并导入你电脑上的剪映专业版。

剪搭子是一套装进 Agent 就能用的 AI 剪辑系统。它先读懂文案，再从素材库挑画面、排节奏，最后加花字、音效、字幕、贴纸、调色和重点标注，产出可继续编辑的剪映草稿。你只需要打开剪映检查、微调、导出。

装上它之后，传素材、做预设、提交任务、等结果、下载草稿并装进剪映，全部交给 Agent；你直接提要求即可。

## 适合剪什么

电商信息流广告、品牌推广、产品推广、个人自媒体、跨境电商广告、实体店铺推广、本地生活等题材，时长 10 秒～3 分钟的短视频。

## 适合谁

- 专业剪辑师、专业剪辑团队
- 品牌方内容团队
- 个人创作者

## 为什么用 Agent 操作剪搭子

- **不用自己操作**：素材导入、预设调整、任务提交、进度跟踪、草稿安装都由 Agent 完成，你只做最后的检查。
- **直接提要求**：不用研究参数怎么填、按钮怎么点，把「节奏快一点」「提到这个卖点就配对应画面」说清楚，Agent 自己判断该怎么调。
- **不用先读文档教程**：遇到问题直接问 Agent，它去查规则和接口再动手。

## 能力

- 项目与三类素材库管理：主素材库、人物口播库、语音配音库。
- 素材导入与索引：百度网盘上传、分享、转存，已有合法分享链接可直接使用；上千条素材不用提前分类。
- 风格与字幕样式预设：系统预设只读，按你的要求另存个人预设；剪映里做好的字幕和固定文字样式，可以通过草稿链接交给它提取。
- 剪辑：旁白剪辑与人物出镜口播都支持，单条或批量提交；批量逐行确认差异。
- 交付：下载草稿包、安全解压、安装到本机剪映草稿目录，同名不会静默覆盖。

## 安装

要求 Node ≥20，并已安装剪映专业版。推荐同时安装官方百度网盘 Skill（`baidu-drive`），用于素材上传与下载。

```bash
npx skills add ElderDoge/MyCutBuddy
```

也可以把本仓库克隆到 Agent 的 skills 目录。安装后 CLI 位于 Skill 根目录的 `scripts/mycutbuddy.mjs`，全部能力通过 `node scripts/mycutbuddy.mjs <命令>` 调用，命令清单以 `help` 输出为准。

## 首次使用

1. 让 Agent 发起账号授权，按提示在浏览器中核对请求方并亲自批准。凭据只保存在本机 `~/.mycutbuddy`，有效期 30 天。
2. 注册即可免费试用，免费积分用完后按量付费。
3. 下载的草稿包会先安全解压，再安装到你实际配置的剪映草稿目录。

## 边界

- 本地草稿安装需要 Agent 具备这台电脑的文件访问权限；纯云端环境只能提供下载信息与手动安装步骤。
- 同一套剪辑能力另有网页工作台入口，但本 Skill 面向 Agent 操作。
