# 积分计费说明（导入 / 索引 / 旁白 / 口播）

本文件只说明服务端（TinyShip）实际执行的计价公式、受理门槛与退款口径。公式是完整的，但能否算出准确金额仍取决于尚未确定的事实，请阅读最后一节。

## 0. 计费总原则

- 服务端是价格、积分账本、扣费与退款的唯一真源。Agent 只做估算与解释，不代替服务端账本。
- 发起任何收费操作前，Agent 必须与用户达成明确的收费约定并确认本操作在约定范围内；可以逐次商议，也可以按用户明确接受的批次或持续约定执行，不固定一种方式。服务端不要求用户回网页逐次批准，也无法验证 Agent 是否真的取得同意。
- 账号授权不等于无限收费；若超出已约定的范围，必须重新与用户商议，不能把设备授权当作费用同意。
- 提交收费请求时会带上服务端给出的提示版本号，表示提交的输入与用户看到的提示一致。服务端无法验证 Agent 是否真的展示过该提示，这部分依赖 Agent 的自觉。
- 每个价格版本独立冻结；已经保存的历史价格快照不会被重新计算。本文件描述当前生效版本。

## 1. 素材导入

计价事实由服务端在扫描、下载与准备完成后冻结，随后自动扣费；受理时不预先知道具体金额。

```
D = 本次导入下载的全部受支持原始素材总字节 / 1_000_000_000
    // includes duplicates and content-level unusable files: the download did happen
S = 去重后本次新增素材的原始总字节 / 1_000_000_000
    // original bytes of the newly added sources, not their stored or compressed size
C = 需压缩的新增源文件数
    // source files planned for compression, not output files, segments or encoding attempts
p = ln(125) / ln(500)
price = ceil( round_half_up_decimal(0.85 * D + 3 * S^p + 0.25 * C, 12) )
```

- 精度：50 位十进制有效数字、ROUND_HALF_UP；`S^p` 同精度；`0.85*D` 与 `0.25*C` 用精确有理数计算。
- 未取整总价先按十进制 ROUND_HALF_UP 保留 12 位小数，最后只 `ceil` 一次；不逐项取整。
- 精确锚点：`S=0` 时存储项为 `0`，`S=1` 时为 `3`，`S=500` 时为 `375`。
- 没有最低消费，也没有单笔上限；可分析素材为空或全部重复时也可以只收很低的费用（例如 1 GB 全部重复约 1 积分，500 GB 全部重复约 425 积分）。
- 被跳过（内容级不可用）的素材计入 D，不计 S 与 C；不会因它们退款、部分退款或二次核价。
- 音频素材无论原样复制还是转成 MP3，都只贡献 D 与 S，对 C 的贡献为 0；重试不重复计量。
- 口径提醒：素材库中现在的体积是压缩、转码、删除不可用文件之后的结果，无法反推 D、S、C。所以不要用入库体积估算导入费用。

## 2. 素材索引

- 只有主素材库与人物口播库可以索引；语音配音库不提供索引，也不计索引费。
- 计入范围：目标库中「已启用」且分析状态为「待分析」或「已失效」的素材。没有这类素材时不收费、不创建报价。
- 单位：图片 = 1 单位；视频与音频 = `max(1, ceil(素材时长秒 / 15))` 单位（15 秒与 16 秒分别为 1 与 2 单位）。
- 价格：`units = 0` 时为 0；否则 `max(1, ceil(units * 7 / 20))`，即每个复杂度单位 0.35 积分。50 / 300 / 500 单位分别约 18 / 105 / 175 积分。
- 复杂度单位不向用户展示；无语音结果（no_speech）是合法成功，不退款。
- 索引报价即扣费金额：受理时冻结一份快照，实际执行不再重新测量。

## 3. 旁白（单轨剪辑）逐行计价

```
// billable characters count only Unicode letters and digits; punctuation, spaces and emoji do not
chars   = audio_source == 'tts' ? billable_char_count(script_text) : 0
seconds = audio_source == 'upload' ? ceil(original_audio_seconds) : ceil(chars / 5)
k       = enable_ai_effect_application ? 1 : 0.8

time_price     = ceil((6 + seconds / 4) * k)
material_extra = ceil(3 * candidate_material_count / 100)
row_price      = time_price + material_extra
batch_price    = sum(row_price)   // per-row ceil, then sum: no batch discount, no batch-level rounding
```

- upload 行的真实原始音频时长（0 < 秒数 ≤ 600）由服务端读取已发布配音素材得到，Agent 只提交真实素材显示路径，不在请求中自填时长；报价期间素材发生变化需要重新提交。不得用 0 秒、默认值或参考文案回退。
- 特效系数只作用于时间价，不作用于候选加价；两项各自向上取整。
- 候选素材数由服务端按库与任务计算，Agent 不自行声明。
- 参考锚点（开特效）：25 字 + 50 候选 = 8 + 2 = 10 积分；150 字 + 150 候选 = 14 + 5 = 19 积分；150 字 + 200 候选 = 14 + 6 = 20 积分；150 字 + 1000 候选 = 14 + 30 = 44 积分；210 字 + 1000 候选但关闭特效 = 14 + 30 = 44 积分；upload 30.1 秒 + 150 候选 = 14 + 5 = 19 积分。
- 旁白的报价就是扣费金额（同一份快照），不会按最终成片重新测量。

## 4. 口播（分段口播 / 完整口播）计价

```
s = ceil(real_duration_us / 1_000_000)                       // real duration in whole seconds
B = 6 + s / 4                                                // keep exact, do not round early
m = 100 - (use_primary_overlay ? 0 : 35) - (enable_ai_effect_application ? 0 : 20)
    // both on: 100, only effects off: 80, only overlay off: 65, both off: 45
N_talking = talking-head candidate count      // server-computed
N_primary = primary material candidate count  // server-computed, only used when overlay is on

// segment_composition path only
S = ceil((24 + s) / 10) + ceil(3 * N_talking / 100)
// both paths
C = ceil((24 + s) * m / 400) + ceil(3 * (use_primary_overlay ? N_primary : 0) / 100)

row_price   = (path == 'segment_composition' ? S : 0) + C    // full_video has no selection stage
batch_price = sum(row_price)   // per-row ceil, then sum
```

- 覆盖与特效系数不打折候选加价；每个阶段的两项分别向上取整。
- 两类入口共用同一公式与同一价格版本：估算与真实阶段消费都是它，区别只在传入的秒数与事实来源。
- 估算秒数：完整口播 = 已发布源时长（必须落在 0 秒以上、600 秒以内，脚本可空且只作字幕校正）；分段口播 = 脚本去空白后非空时 `max(1, ceil(L/5))`（`L` 只计脚本的 Unicode 字母与数字），脚本为空而指令非空时为 30 秒。指令长度不计费，也不影响估算。
- 实际费用按节点回报的合法正式阶段事实计算：选段完成计 S，成片就绪计 C。测试（预检）不收费。
- 参考锚点：30 秒、覆盖与特效均关闭、3 个口播候选时 `S=7`、`C=7`、合计 14 积分（估算与实际同口径）。

## 5. 受理余额门槛与欠账

- 新素材导入按目标库的实时余额受理：主素材库要求 ≥ 50 积分；人物口播库与语音配音库要求 ≥ 1 积分。恰好等于门槛允许受理；低于门槛（含 0 与负数）直接拒绝，不创建请求、准备记录、投递或消费。
- 该门槛是本次导入唯一的余额准入。准备完成后的自动续行不再校验余额，扣费允许把余额扣成负数并照常压缩、入库，不产生退款或清理义务。欠账只影响后续操作。
- 旁白与索引：任务下发前按价格原子扣费，余额不足则该请求失败且不产生部分状态（不透支）。
- 口播：不下发前预扣，也不冻结或预留余额。受理时只要求实时余额 > 0；余额为 0 或负数直接拒绝并给出补充积分指引。页面按估算总和 100% 比较余额属于页面规则，服务端不以估算金额作为准入门槛，也不把用户对估算的确认当作余额证明。真实费用可以超过估算并使余额为负，且不会因此中断交付。
- 测试口径：口播测试只预检、不收费；旁白与索引的测试与正式同价（同样一次扣费）。

## 6. 取消与退款

退款一律以服务端账单为准：已交付或已成功的部分保留费用，没有发生过消费就没有退款。

- 旁白（单轨）：下发前扣费。在节点确认接收（ACK）之前可以取消，取消或整批失败时全额退还该批费用；ACK 之后用户不能取消。批次部分交付时，按未交付行各自的原价返还（成功交付行保留原价），全部交付不退款。退款按冻结的行原价，不按参考文案、重新测量或后处理长度重算。
- 素材索引：下发前扣费；失败或取消时全额退还本次索引费。无 eligible 不收费，无语音结果合法成功不退款。
- 素材导入：
  - 扣费前取消：停止下载与处理并清理临时产物，没有消费也就没有退款。
  - 扣费后、节点 ACK 之前取消：立即取消该次续行并全额退款，同时仍执行临时产物清理。
  - ACK 之后取消：等待节点自身的取消或失败终态；失败或取消时全额退还该次导入费，成功完成则保留消费。
  - 跳过的不可用素材不产生退款或部分退款。
- 口播（按阶段结算，不预扣）：
  - 只有合法正式阶段事实产生费用；是否退还已经产生的阶段费用，按下面的终止原因与交付集合决定。
  - 系统失败（组接、成片、上传失败或执行超时到期）：未交付行按各自已计的 S 与 C 全额退还。
  - 用户主动取消：允许在终止原因冻结前取消（含 ACK 之后）；已完成选段的 S 保留，只退还未交付行的 C。
  - 终止原因与已接受的交付集合首次冻结后不再改变。迟到的合法阶段事实仍会先记录原消费，再按已冻结的原因形成对应退款；各阶段累计退款不超过其原消费。
  - 口播阶段扣费允许把余额扣成负数；退款同样以服务端账单为准。

## 7. 估算与误差

- 估算依赖尚未确定的事实：导入的原始体积与去重结果、候选素材数量、upload 音频的真实时长、口播的真实时长与阶段成败。
- 导入在准备完成前无法给出金额；旁白与索引的报价就是扣费金额；口播的估算与实际可能不同。
- 因此估算不是最终报价，也不是费用上限。实际扣费与退款以服务端账单为准。不要用压缩或转码后的入库体积反推导入费用，也不要向用户承诺「到达预算线就会停止」。

## 8. 暂不支持

- 个人音乐（背景音乐）与个人音色（配音音色）预设的导入与管理是规划中的最终目标，但当前没有任何可用接口与计费实现。请勿按规划中的口径向用户承诺价格或计费。
