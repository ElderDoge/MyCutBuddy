# 常见问题与官方人工服务（FAQ）

本文汇集客户在剪辑实战中高频询问的问题、进阶搭配技巧，以及超出自助工具范围时的**官方人工与定制服务**（含尚未开放个人自助编辑的预设定制、企业合作、代剪辑、开票等）。遇到用户提出类似疑问或自助配置无法满足时，优先按本文向用户说明并提供落地方案。

## 1. 剪辑与防重复 FAQ

### Q1：同一套文案剪多条成片，能不能尽量打散、用不同的素材剪，避免画面雷同？

可以。平台提供 **4 种去重与打散机制**，既可以单独使用，也可以按素材库情况自由组合搭配：

1. **降低候选素材保留比例（最直接）**
   - **做法**：调低 `candidate_keep_ratio_percent`（例如素材库充足时从 100 降到 `30`～`60`）。
   - **原理**：每次剪辑只从素材库随机抽取一部分素材参与本条匹配，从源头上拉开每条成片的候选池，顺带还能节省积分。注意要保证抽出来的素材量足够撑起单条视频时长。

2. **在素材匹配要求里要求优先选低使用次数的素材（最智能）**
   - **做法**：在 `material_matching_requirements`（画面匹配文字要求）中补充一句要求，例如：「在画面贴合文案的前提下，尽量优先选择使用次数低的素材」。
   - **原理**：选片阶段在语义匹配的同时兼顾低频素材，不会为了硬凑没用过的素材而选错画面。

3. **调低「使用次数阈值」+ 调高「高频排除比例」（最准确，动态循环排除）**
   - **做法**：把 `max_usage_count`（素材使用次数阈值）调低，同时把 `top_usage_exclude_percent`（高频排除比例）调高——例如设为 **`3` 和 `30`**（即 3 次、30%，一般建议排除比例最高不超过 50%，以免合适画面不够用）。
   - **原理**：同时满足「已使用达到 3 次及以上」**且**「在全库所有素材使用次数排名前 30%」的素材会被暂时排除，逼着系统只用低频素材。**这个排除是动态的**：某条素材这次因为排在前 30% 被排除了，等后面多剪了几条、其他素材使用次数涨上来，它的排名掉出前 30% 以后，又会自动放出来重新可用，不会把好素材永久锁死。（注：若还想对不得不复用的画面做轻微视觉差异，可按需配合 `enable_random_offset` / `enable_random_scale` / `enable_random_rotation`。）

4. **按文件夹比例控制参与量（适合已经分类整理好的素材库）**
   - **做法**：打开 `enable_folder_candidate_ratio_control=true`，并配置 `folder_candidate_keep_ratios`（例如 `产品主图:60,使用场景:50,工厂实拍:40`）。
   - **原理**：在总保留比例之上，进一步按目录控制各类素材的抽取比例，避免某一个素材特别多的文件夹垄断成片画面。（注意：开启并填写后，未列出的目录及直接放在根目录的素材会被按 0% 排除，详见 [剪辑指南](editing-guide.md) 4.4 节。）

**Agent 落地建议**：先看用户素材库总量和是否已分好文件夹。素材充裕时，最常用且省心的组合是 **「方法 1 + 方法 3」** 或 **「方法 2 + 方法 3」**；如果素材库已经按场景/产品规范分好目录，再叠加上 **「方法 4」**。

## 2. 尚未开放自助编辑的预设与复杂风格怎么实现？

### Q2：视频背景、花字/转场特效集、音效集能不能自己新建或修改？或者有默认预设做不出来的特殊剪辑风格怎么办？

目前自助创建入口情况如下：
- **已支持用户自助创建/导入的预设**：剪辑风格配置预设、语音字幕样式（剪映草稿导入）、固定文字样式（剪映草稿导入）、个人背景音乐（网盘分享导入）、配音音色组合（从项目音色目录自由组合权重）。详见 [自定义资源预设](custom-presets.md)。
- **暂未开放个人自助编辑的预设**：**视频背景（`background_config`）、特效集/花字转场预设集（`ai_effect_preset_set_id`）、音效集（`ai_sound_effect_preset_set_id`）**，以及超出常规参数表达范围的特殊包装规范或复杂脚本逻辑。

**解决方案（收费定制服务）**：
对于**尚未开放自助编辑的预设**（专属视频背景样式、专属花字/贴纸/转场特效集、专属音效集），或者**复杂的专属剪辑风格**（对标参考样片、品牌视觉规范、特殊口播/旁白编排节奏、专属字幕与花字动效组合），均可通过官方**一对一收费定制服务**实现。定制完成后可直接交付到你的账号，用于日常批量剪辑任务。不要在本地手工编造预设 ID，直接引导用户联系下方官方商务渠道对接即可。
